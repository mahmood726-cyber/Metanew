## 🔒 SAFEGUARDS: ZERO-HALLUCINATION GUARANTEE

### 1. Number Locking Mechanism

**Purpose:** Prevent AI from modifying any statistics

```r
lock_numbers <- function(text) {
  # Extract all numbers BEFORE NLP processing
  numbers <- str_extract_all(text, "\\d+\\.?\\d*")[[1]]

  return(list(
    original_text = text,
    locked_numbers = numbers,
    number_positions = positions
  ))
}

validate_numbers_unchanged <- function(original_locked, nlp_output) {
  output_numbers <- str_extract_all(nlp_output, "\\d+\\.?\\d*")[[1]]

  if (!identical(sort(original_locked$locked_numbers), sort(output_numbers))) {
    warning("NLP MODIFIED NUMBERS - REVERTING TO TEMPLATE TEXT")
    return(FALSE)  # REJECT NLP output
  }

  return(TRUE)  # ACCEPT NLP output
}
```

**Result:** AI **cannot** change "RR 0.75" to "RR 0.73" or add fabricated P-values.

### 2. Template Similarity Check

**Purpose:** Prevent AI from introducing new claims

```r
check_template_similarity <- function(template_text, nlp_output) {
  # Remove numbers (validated separately)
  template_words <- tokenize(template_text)
  output_words <- tokenize(nlp_output)

  # Jaccard similarity
  similarity <- length(intersect(words)) / length(union(words))

  if (similarity < 0.85) {
    warning("NLP OUTPUT TOO DIFFERENT FROM TEMPLATE - REVERTING")
    return(FALSE)  # REJECT - too different from approved template
  }

  return(TRUE)  # ACCEPT - similar enough to template
}
```

**Result:** AI can rephrase for fluency but cannot add medical claims not in template.

### 4. Fallback to Templates

**Purpose:** Guarantee output even if NLP fails

```r
if (use_nlp) {
  locked <- lock_numbers(template_text)
  nlp_output <- nlp_polish_text(template_text)

  # Validate
  if (validate_numbers_unchanged(locked, nlp_output) &&
      check_template_similarity(template_text, nlp_output)) {
    final_text <- nlp_output  # Use polished version
  } else {
    message("NLP validation failed - using template text")
    final_text <- template_text  # Fallback to template
  }
}
```

**Result:** Always generates output, even if NLP unavailable or validation fails.
