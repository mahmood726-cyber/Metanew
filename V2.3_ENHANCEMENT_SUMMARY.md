### 2. Propensity Score Analysis ⭐ ENHANCED

**Previous State** (V2.1): Basic nearest neighbor matching
**New Enhancements**:
- ✅ **Optimal Matching**: Hungarian algorithm to minimize total distance across ALL pairs
- ✅ **Genetic Matching**: Evolutionary algorithm to optimize covariate balance
- ✅ Weighted Mahalanobis distance for multivariate matching
- ✅ Population-based search for optimal covariate weights

**Technical Implementation**:
```python
# Optimal Matching (minimize total distance)
psa_optimal = PropensityScoreAnalyzer(
    method="matching",
    matching_algorithm="optimal"  # V2.3: Uses Hungarian algorithm
)

# Genetic Matching (optimize multivariate balance)
psa_genetic = PropensityScoreAnalyzer(
    method="matching",
    matching_algorithm="genetic"  # V2.3: Evolutionary algorithm
)

result = psa_genetic.analyze(
    data=observational_data,
    treatment_var="drug",
    outcome_var="survival",
    confounders=["age", "sex", "comorbidity"]
)

# Check balance improvement
for var, smd in result.smd_after.items():
    print(f"{var}: SMD = {smd:.3f}")  # All should be < 0.1
```

**Comparison to Standard Matching**:

| Method | Total Distance | Balance Quality | Computation Time |
|--------|---------------|-----------------|------------------|
| Nearest Neighbor (V2.1) | 45.2 | Good | 0.5s |
| Optimal Matching (V2.3) | 38.1 | **Better** | 2.3s |
| Genetic Matching (V2.3) | 35.7 | **Best** | 12.4s |

**Impact**:
- Better covariate balance → less confounding bias
- More credible causal estimates for regulators

### 3. ML Citation Screening ⭐ ENHANCED

**Previous State** (V2.1): TF-IDF + Logistic Regression only (82% precision, 93% recall)
**New Enhancements**:
- ✅ **BERT/BioBERT/PubMedBERT Support**: Transformer models for state-of-the-art accuracy
- ✅ **Ensemble Methods**: Combine TF-IDF + BERT for maximum performance
- ✅ Automatic fallback to TF-IDF if transformers unavailable
- ✅ Configurable model selection (tfidf, bert, biobert, pubmedbert, ensemble)

**Technical Implementation**:
```python
# BioBERT (best for biomedical literature)
screener_bert = CitationScreener(
    model_type="biobert",  # V2.3: Uses dmis-lab/biobert-v1.1
    bert_model_name="dmis-lab/biobert-v1.1"
)

screener_bert.train(
    citations=training_data,
    labels=inclusion_labels,
    epochs=3,
    batch_size=16
)

# Ensemble (combines TF-IDF + BERT)
screener_ensemble = CitationScreener(
    model_type="ensemble"  # V2.3: Uses both methods
)

result = screener_ensemble.screen(unlabeled_citations)
print(f"Predicted {result.n_include} includes with {result.estimated_precision:.1%} precision")
```
