## 📋 FEATURE 1: UME Consistency Model

### Overview
**Unrelated Mean Effects (UME)** - Alternative to design-by-treatment interaction model for detecting inconsistency in NMA.

**Why Essential:**
- More powerful than traditional node-splitting
- Recommended by NICE TSD 4
- Complements existing consistency checks
- Closes gap in current NMA capabilities

### Technical Specification

**Statistical Method:**
```r
# UME Model Specification
# Instead of d[i,k] = mu[i] + delta[i,k]
# Use: theta[i,k] = baseline effect + design effect + UME

# For each design d and treatment comparison k:
# theta_d,k ~ N(d_k, tau²)  # Unrelated across designs

# Compare to consistency model:
# theta_d,k ~ N(d_k_common, tau²)  # Shared across designs

# Inconsistency test:
# Deviance difference: D_consistency - D_UME
# If significant → inconsistency detected
```

### Overview
**Component NMA** - Decomposes complex interventions into individual components to identify which parts drive effectiveness.

**Why Game-Changing:**
- Answers "Which component works?" (not just "Does it work?")
- Essential for complex interventions (e.g., CBT components, drug combinations)
- No competitor has this capability
- High academic/clinical impact

### Technical Specification

**Statistical Method:**
```r
# Component NMA Model
# Treatment effect = Σ(component effects) + interaction effects

# For treatment k with components c1, c2, c3:
# d_k = β_c1 + β_c2 + β_c3 + β_c1:c2 + β_c1:c3 + β_c2:c3

# Additive model (no interactions):
# d_k = Σ β_c

# Interactive model (with synergy):
# d_k = Σ β_c + Σ β_c1:c2

```

## 📋 FEATURE 3: Dose-Response Network Meta-Analysis

### Overview
**Dose-Response NMA** - Combines dose-response modeling with network meta-analysis to find optimal doses across treatment networks.

**Why Essential:**
- Answers "What dose is best?" across multiple treatments
- More powerful than pairwise dose-response
- Critical for drug development and guideline recommendations
- Extends existing dose-response module to networks

### Technical Specification

**Statistical Method:**
```r
# Dose-Response NMA Model
# Combines fractional polynomials with NMA

# For treatment k at dose d:
# log(RR_k,d) = α_k + β_k1 * d^p1 + β_k2 * d^p2

# Network constraint:
# α_k = reference + network effect

# Dose-response parameters: β_k1, β_k2, p1, p2
# Estimated jointly across network
```

## 📋 FEATURE 4: RMST Network Meta-Analysis

### Overview
**Restricted Mean Survival Time (RMST) NMA** - Network meta-analysis using RMST instead of hazard ratios for survival outcomes.

**Why Superior to HR:**
- Clinically interpretable ("2.3 months longer survival")
- Doesn't require proportional hazards assumption
- Better for non-proportional hazards (immunotherapy, late effects)
- Recommended by regulatory agencies (FDA, EMA)

### Technical Specification

**Statistical Method:**
```r
# RMST Calculation
# RMST(t*) = ∫[0 to t*] S(t) dt
# Where S(t) is survival function

# For NMA:
# RMST difference: Δ_RMST = RMST_treatment - RMST_control

# Network model:
# Δ_RMST_k,ref ~ N(d_k, σ²)  # Random effects NMA

# Can handle:
# - RMST directly (if reported)
# - Reconstructed from KM curves
# - Calculated from IPD
```

- NMA allows ranking of multiple diagnostic tests
- Bivariate model required (sens/spec correlation)
- High demand in diagnostic research

# Bivariate NMA for DTA
# Models sensitivity and specificity jointly

# μ_sens[k] = baseline + δ_sens[k]

## 📋 FEATURE 7: Real-World Evidence Integration

### Overview
**RWE Integration** - Methods to combine randomized controlled trials (RCTs) with observational real-world evidence (RWE).

**Why Critical:**
- RCTs lack external validity (narrow populations)
- RWE provides real-world effectiveness
- Regulatory agencies (FDA, EMA) encourage RWE
- Transportability methods enable principled integration

### Technical Specification

**Statistical Method:**
```r
# Transportability Framework
# Goal: Generalize RCT results to target population using RWE

# Step 1: Estimate treatment effect in RCT
# TE_RCT = E[Y(1) - Y(0) | RCT population]

# Step 2: Estimate effect modifiers from RWE
# Identify covariates X where:
# TE_RCT(X) ≠ TE_target(X)

# Step 3: Re-weight or transport
# TE_target = Σ w_i * TE_RCT(X_i)
# Where w_i = P(X_i | target) / P(X_i | RCT)

# Methods:
# - Inverse odds weighting
# - Doubly robust estimation
# - Bayesian hierarchical models
```
