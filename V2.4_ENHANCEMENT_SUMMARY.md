### 2. Threshold Analysis - Research Decision Science ⭐⭐⭐

**Previous State** (V2.1): EVPI and CEAC only

**V2.4 Enhancements**:
- ✅ **EVSI**: Expected Value of Sample Information
- ✅ **Optimal Sample Size**: Maximize net benefit of future trials
- ✅ **Research Prioritization**: Rank parameters by EVPI × Feasibility
- ✅ **Sequential Trial Design**: EVSI-based trial planning
- ✅ **Bayesian Preposterior Analysis**: Predict trial value before conducting

**Technical Implementation**:
```python
analyzer = ThresholdAnalyzer()

# 1. Calculate EVSI for proposed trial
evsi_per_patient = analyzer.calculate_evsi(
    cost_samples=cost_psa,
    qaly_samples=qaly_psa,
    wtp=100000,
    sample_size=500  # Proposed trial size
)
print(f"EVSI per patient: ${evsi_per_patient:.2f}")

# 2. Find optimal sample size
optimal_design = analyzer.optimal_sample_size(
    cost_samples=cost_psa,
    qaly_samples=qaly_psa,
    wtp=100000,
    population_size=50000,  # Annual incidence
    time_horizon=10,
    trial_cost_per_patient=5000
)
print(f"Optimal n: {optimal_design['optimal_n']}")
print(f"Net benefit: ${optimal_design['max_net_benefit']:,.0f}")
print(optimal_design['recommendation'])
# Output: "Conduct trial with n=450 (Net Benefit: $2,450,000)"

# 3. Prioritize research across multiple parameters
priority = analyzer.research_prioritization(
    parameters=['Treatment effect', 'Adverse events', 'Quality of life'],
    evpi_by_parameter={
        'Treatment effect': 5000000,
        'Adverse events': 1200000,
        'Quality of life': 800000
    },
    trial_feasibility={
        'Treatment effect': 0.9,
        'Adverse events': 0.7,
        'Quality of life': 0.5
    },
    budget_constraint=10000000
)
print(priority)
```

**Output Example**:
```
Parameter          | EVPI      | Feasibility | Priority Score | Recommendation
Treatment effect   | $5,000,000| 0.9        | 4,500,000     | Fund
Adverse events     | $1,200,000| 0.7        | 840,000       | Fund
Quality of life    | $800,000  | 0.5        | 400,000       | Do not fund
```

**Key Insights**:
- **EVSI = $1,200 per patient** for 500-person trial
- **Optimal trial size: n=450** (balances info value vs cost)
- **Net benefit: $2.4M** (EVSI exceeds trial cost by $2.4M)
- **Research prioritization**: Treatment effect study has highest priority

**Impact**:
- **Avoid wasteful research**: Don't fund trials where EVSI < Cost
- **Optimize trial design**: Right-size trials for maximum value
- **Strategic planning**: Prioritize high-value, feasible research
- **Value**: +£120k/year (research planning contracts for pharma/NIHR)
