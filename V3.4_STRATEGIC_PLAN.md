## 📦 DETAILED FEATURE SPECIFICATIONS

### Feature 1: Budget Impact Analysis (BIA)

**Technical Approach:**
- 5-year time horizon (standard)
- Population-based projections
- Market uptake scenarios
- Sensitivity analyses

**Key Inputs:**
1. **Population Parameters:**
   - Eligible population (year 1)
   - Population growth rate (annual)
   - Prevalence/incidence

2. **Treatment Parameters:**
   - Current therapy costs (per patient per year)
   - New therapy costs (per patient per year)
   - Administration costs
   - Monitoring costs

3. **Market Dynamics:**
   - Uptake scenarios (pessimistic, realistic, optimistic)
   - Market share curve (S-curve or linear)
   - Displacement of current therapies

4. **Time Horizon:**
   - Years to project (default 5)
   - Discount rate (if applicable)

**Calculations:**

**Budget Impact = Σ (New Scenario Costs - Current Scenario Costs)**

**For each year:**
```
Population_year = Population_baseline × (1 + growth_rate)^year

Patients_treated_new = Population_year × market_share_year

Cost_new_scenario = (Patients_treated_new × Cost_new_therapy) +
                    (Remaining_patients × Cost_current_therapy)

Cost_current_scenario = Population_year × Cost_current_therapy

Budget_impact_year = Cost_new_scenario - Cost_current_scenario
```

**Sensitivity Analyses:**
- One-way sensitivity (vary each parameter)
- Scenario analysis (pessimistic/realistic/optimistic)
- Threshold analysis (break-even market share)

**Outputs:**
1. **Summary Table:**
   - Year-by-year budget impact
   - Cumulative budget impact
   - Cost per additional patient treated

2. **Visualizations:**
   - Budget impact over time (line chart)
   - Cumulative budget impact (area chart)
   - Tornado diagram (one-way sensitivity)
   - Scenario comparison (grouped bar chart)

3. **Export:**
   - Excel template (editable for customization)
   - Word report
   - PDF summary

**File:** `frontend/modules/budget_impact.R`

**Estimated Lines:** ~600

### Feature 2: Multi-Criteria Decision Analysis (MCDA)

**Technical Approach:**
- Weighted scoring framework
- Multiple criteria across domains
- Stakeholder preference elicitation
- Sensitivity to weights

**Key Concepts:**

**MCDA Score = Σ (Criterion_Score_i × Weight_i)**

**Standard MCDA Process:**
1. Define decision problem
2. Identify alternatives (treatments)
3. Select criteria (efficacy, safety, cost, convenience)
4. Score alternatives on each criterion
5. Elicit criterion weights (importance)
6. Calculate overall scores
7. Sensitivity analysis

**Criteria Domains:**
1. **Clinical Effectiveness:**
   - Mortality reduction
   - Morbidity reduction
   - Quality of life improvement

2. **Safety:**
   - Serious adverse events
   - Treatment discontinuation
   - Long-term safety

3. **Economic:**
   - Cost-effectiveness (ICER)
   - Budget impact
   - Affordability

4. **Implementation:**
   - Ease of use
   - Administration burden
   - Monitoring requirements

5. **Equity & Ethical:**
   - Equity of access
   - Severity of disease
   - Unmet need

**Weighting Methods:**
- **Direct weighting** - Assign weights directly (sum to 100%)
- **Swing weighting** - Compare criterion importance via hypothetical swings
- **AHP (Analytic Hierarchy Process)** - Pairwise comparisons

**Scoring:**
- Linear scale (0-100)
- Normalized based on best/worst performers
- Can use meta-analysis results directly

**Outputs:**
1. **MCDA Matrix:**
   - Rows: Alternatives (treatments)
   - Columns: Criteria
   - Cells: Scores (with weights)

2. **Overall Scores:**
   - Weighted total for each alternative
   - Rank order

3. **Visualizations:**
   - Radar/spider chart (performance profile)
   - Stacked bar chart (contribution by criterion)
   - Tornado diagram (sensitivity to weights)
   - Dominance analysis (pairwise comparisons)

4. **Sensitivity Analysis:**
   - Vary weights ±25%
   - Monte Carlo simulation of weights
   - Threshold weight analysis

**File:** `frontend/modules/mcda.R`

**Estimated Lines:** ~700

### Feature 3: PSA Dashboard Enhancement

**Technical Approach:**
- Enhance existing BCEA integration
- Add advanced visualizations
- Interactive parameter exploration

**New Visualizations:**

**1. Cost-Effectiveness Acceptability Curve (CEAC)**
- Already exists in BCEA, enhance with:
  - Multiple strategies on one plot
  - Threshold probability slider (real-time update)
  - Probability readout at specific thresholds

**2. Cost-Effectiveness Acceptability Frontier (CEAF)**
- **Purpose:** Shows which strategy has highest probability of being cost-effective at each threshold
- **Math:** For each threshold λ:
  - Calculate Pr(Cost-Effective | λ) for each strategy
  - Plot max probability across strategies
  - Indicate which strategy is optimal

**3. Expected Loss Curves**
- **Purpose:** Expected opportunity loss of choosing each strategy
- **Math:** OL(strategy) = E[max(NMB_all) - NMB_strategy]
- **Interpretation:** Cost of being wrong

**4. Expected Value of Perfect Information (EVPI)**
- **Already exists** in evppi.R
- Enhance with:
  - Population EVPI (scale up to population)
  - Time horizon consideration

**5. Incremental Net Monetary Benefit (INMB) Distribution**
- **Purpose:** Show distribution of INMB between strategies
- **Visualization:** Histogram/density plot
- **Interpretation:** Quantifies uncertainty in decision

**6. Cost-Effectiveness Plane Enhancements**
- Add:
  - Confidence ellipse (95%)
  - WTP threshold ray
  - Quadrant probability labels
  - Zoom controls

**Interactive Features:**
- **WTP Threshold Slider:**
  - Drag to change willingness-to-pay
  - All plots update in real-time
  - Optimal strategy highlighted

- **Strategy Selector:**
  - Toggle strategies on/off
  - Compare subsets

- **Parameter Exploration:**
  - Click on a plot point
  - See underlying parameter values

**Export:**
- High-resolution plots (publication quality)
- Interactive HTML dashboard
- Excel tables with all data

**File:** `frontend/modules/psa_dashboard.R`

**Estimated Lines:** ~500
